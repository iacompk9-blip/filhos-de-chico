# Filhos de Chico — Site

Site estático, mobile-first, pronto para GitHub + Vercel.

## Arquivos
- index.html
- style.css
- script.js
- assets/

## Publicação na Vercel
1. Crie um repositório no GitHub.
2. Envie todos os arquivos desta pasta para o repositório.
3. Na Vercel, clique em Add New Project.
4. Selecione o repositório.
5. Como é um site HTML/CSS/JS puro, não precisa de build command.
6. Publique.

## Observação
Os textos, telefone, endereço, horários, Instagram, link de localização e link direto de avaliação já estão preenchidos.
Os botões de WhatsApp são configurados no script.js e usam mensagens diferentes por categoria.
